🗺️ Memory Map & Community Map Help

Learn how to pin your travel memories and explore public trip albums shared by the community.

📌 Understanding the Two Maps

Your travel app has two complementary map experiences:

  • Memory Map (Travel Memories) — Your personal map. Pin photos from your trips, choose who can see them, organize them into albums, and manage everything you upload.
  • Community Map — The public discovery map. Explore memories that travelers have shared publicly, search by city, like and comment, and browse trip albums from the community.

Both maps are focused on Sri Lanka and use interactive pins with clustering so you can easily explore locations.

Memory Map – Pin & Relive Your Journeys

Use the Memory Map to capture and organize your own travel memories. Everything you pin here belongs to you and can be set to Private, Trip Members, or Public.

🎯 Getting Started

1

Open Memory Map

Go to Travel Memories / Memory Map from the main menu. You will see a sidebar and a full map of Sri Lanka.

2

Choose “Add Memory”

In the sidebar, select the Add Memory tab to start creating a new pin.

3

Select a Trip

Pick an existing trip from the dropdown. Memories are grouped into albums by trip name.

Setting the Location

  1. Type a city or place name in Sri Lanka (e.g. Galle, Kandy, Ella).
  2. Click Find or press Enter.
  3. Select the correct result from the dropdown (or it may auto-select if there is only one match).
  4. The map will fly to that location and mark it as ready to save.

Only locations inside Sri Lanka are accepted.

📸 Adding Memory Details & Photo

  1. Enter a Memory Title.
  2. Optionally write a short description of the moment.
  3. Upload a photo (PNG or JPG, max 2 MB).
  4. Choose visibility (see below).
  5. Click Save & Pin to Map.

🔒 Visibility Options

🔒

Private

Only you can see this memory. Perfect for personal keepsakes.

👥

Trip Members

Visible only to people who are members of the selected trip.

🌐

Public

Anyone can see it on the Community Map. Others can like and comment.

📚 My Albums

Switch to the My Albums tab to see your memories grouped by trip. Hover over an album to start a slideshow of its photos. Click an album or a map pin to open the full lightbox view.

  • Delete a single memory — Use the delete button in the lightbox or on the map popup.
  • Delete an entire album — Removes all memories in that trip album (confirmation required).

🌍 Community Map – Explore Public Trip Albums

The Community Map shows only memories that travelers have marked as Public. Discover popular spots, browse trip albums, like photos, and leave comments.

🎯 Main Features

1

Popular Memories

See top-rated public memories ranked by a smart score (likes + recency). Sort by Score, Date, Likes, or Location.

2

Public Albums

Memories are grouped into trip albums. Hover to preview a slideshow, click to open the full album.

3

Interactive Map

Click any pin to see a preview popup. Click “Open details” to view the full memory with likes and comments.

🔍 Searching

Use the search box in the sidebar to filter by city name (e.g. Galle, Kandy). Results update on both the list and the map.

❤️ Liking Memories

  • Like individual memories from the Popular list, album cards, map popup, or lightbox.
  • Like an entire album at once with the album like button.
  • Your likes help determine the Popular ranking (score combines likes and how recent the memory is).

💬 Comments

Open any public memory to view and add comments. You can delete your own comments. Comments are only available on Public memories.

🗺️ Shared Map Features

  • Custom Photo Pins — Each memory appears as a photo pin with a location badge.
  • Marker Clustering — Nearby pins group together. Click a cluster to expand or zoom.
  • Same-location Spiderfy — Multiple memories at the exact same spot fan out when you click the cluster.
  • Lightbox View — Full-screen image viewer with previous/next navigation for albums, details, likes, and comments.
  • Sri Lanka Bounds — The map is limited to Sri Lanka for a focused travel experience.

💡 Tips for Best Experience

💡

Use clear titles and accurate locations so your public memories are easy to discover.

💡

Keep a mix of Private and Public memories — share the best moments, keep personal ones private.

💡

On Community Map, try sorting by Score to see trending recent memories, or by Likes for all-time favorites.

💡

Hover over album cards to quickly preview the photos inside without opening them.

❓ Common Questions

Why don’t I see my memory on the Community Map?

Only memories set to Public appear on the Community Map. Private and Trip Members memories stay on your personal Memory Map.

Can I change visibility after uploading?

Currently visibility is set when you save the memory. To change it you would need to delete and re-upload with the desired setting (or check if edit functionality is available in your version).

What happens if I delete a memory?

Deletion is permanent. It is removed from your albums, the map, and (if it was public) from the Community Map. Album deletion removes every memory in that trip group.

Why is the map limited to Sri Lanka?

The app is designed for travel experiences within Sri Lanka, so the map bounds and location search are restricted to the island.

How is the “Score” calculated on Popular Memories?

Score combines the number of likes with how recent the memory is. Newer memories with more likes rank higher. The score is fixed on page load and only updates when likes change.

Can I comment on private memories?

No. Comments and public likes are only available on memories set to Public.
